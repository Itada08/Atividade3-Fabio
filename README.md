# Página do Flamengo — Atividade da Disciplina (Git/GitHub)

Este repositório contém a atividade prática desenvolvida na disciplina de
Git/GitHub deste semestre.

## Sobre o projeto

Site simples sobre o Clube de Regatas do Flamengo, usado como exercício de
versionamento com Git e publicação no GitHub. Contém:

- Página inicial (`index.html`)
- Estilos (`style.css`)
- Interatividade em JavaScript (`script.js`) — lista de títulos e cards de
  jogadores gerados dinamicamente
- Pasta `img/` com 3 imagens ilustrativas (escudo, Maracanã e bola)

## Como usar

Basta abrir o arquivo `index.html` no navegador, ou usar a extensão
"Live Server" no VS Code.
